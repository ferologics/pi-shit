# VISION

This repo is the monorepo source of truth for my Pi setup.

## Goals

- Keep a small, opinionated set of Pi extensions, skills, and themes
- Prefer monorepo-first development with downstream mirrors published from here
- Build tools that feel native inside Pi instead of relying on loose external glue
- Keep implementation practical, readable, and easy to maintain

## What belongs here

- Extensions that improve my day-to-day Pi workflow
- Skills that package repeatable research / packing / utility workflows
- Theme assets that keep the overall setup coherent

## Direction

- Reuse good ideas from external tools when useful
- Own the workflow shape locally
- Start simple, then replace weak dependencies with native implementations when the value is clear
